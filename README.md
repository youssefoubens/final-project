# 📚 Book Search Backend API

A backend application built with **Express.js** that allows users to **register**, **log in**, and **search for books** using **title** or **ISBN**. This project was developed as part of the **Express.js Certification** on Coursera.

## 🚀 Features

- ✅ **User Authentication** (Sign up / Login)
- 🔐 **Password Hashing** using `bcrypt`
- 🔍 **Search Books** by **Title** or **ISBN**
- 🌐 Integration with a sample book dataset or external API
- 🔧 RESTful API endpoints using Express.js
- 🧱 Clean project structure with routing and middleware

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **bcrypt**
- **body-parser**
- **uuid** (for user ID generation)
- **Book data source** (JSON or API)
